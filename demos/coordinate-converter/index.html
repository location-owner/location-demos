📍 单条地址查询

📦 批量转换说明

1. 点击顶部 📥 导入文件 上传包含地址列的 Excel/CSV/TXT 文件
2. 系统会自动识别地址列，或手动选择列映射
3. 点击 🚀 批量转换 开始地理编码（每秒最多5次请求）
4. 转换完成后可在表格中查看结果并导出

🗺️ 单条逆地理编码

📦 批量逆地理编码说明

1. 上传包含经度列和纬度列的文件（列名可识别如 lng, lat, 经度, 纬度）
2. 系统会自动识别经纬度列，或手动选择列映射
3. 点击 🚀 批量转换 开始逆地理编码
4. 结果会追加省、市、区、详细地址、行政区代码等字段

🔍 单条门店名称查询

📦 批量转换说明

1. 点击顶部 📥 导入文件 上传包含门店名称列的 Excel/CSV/TXT 文件
2. 进入 📍 地址 → 经纬度 页面，批量转换时选择「门店名称列」
3. 系统会优先使用门店名称搜索POI坐标，失败后自动降级为地址编码
4. 转换完成后可在表格中查看结果（含POI名称、POI地址、匹配类型等信息）

📊 数据分析与清洗

导入数据后可进行以下操作：
• VLOOKUP - 将当前表格列与参考表匹配，拉取对应数据
• 去重 - 基于某列或多列去除重复行
• 去空格 - 右键列头 → 清洗 → 去空格
• 提取数字 - 从文本列中提取数字
• 提取省/市/区 - 从地址列中切分行政区划
• POI交叉验证 - 用门店名称+经纬度调高德API验证是否为同一家门店
• 条件筛选 - 类似FILTER，多条件过滤数据
• 计算列 - 自定义公式计算（如距离、算术运算）

❓ 帮助与分享

🔒 数据安全：这是一个纯前端工具，所有文件在浏览器本地处理，不会上传至任何服务器。关闭页面后数据不会残留。

📤 分享给他人：

  • 直接发送 index.html 文件即可（微信/邮件/U盘/共享文件夹）
  • 对方用任意浏览器（Chrome/Edge/Firefox）打开即用
  • 无需安装任何软件，无需联网（地理编码功能除外）
  • 每个人需配置自己的高德 API Key（免费申请）

🌐 部署到服务器：

  • 上传到任意静态文件服务器即可（Nginx/Apache/GitHub Pages）
  • 或使用 npx http-server 在局域网分享

📊 支持的功能：

  • 导入/导出：XLSX、CSV、TXT
  • 地理编码：地址→经纬度（需高德API Key）
  • 逆地理编码：经纬度→地址（需高德API Key）
  • 数据分析：VLOOKUP、去重、筛选、去空格、提取数字/省市区
  • 计算列：距离公式、自定义公式
  • 数据持久化：IndexedDB 保存历史任务

⚙️ 技术特性：基于 SheetJS 引擎，支持 Excel 全格式（16384列）
